= Configuring role-based access control for AI workloads

[role="_abstract"]
Configure role-based access control (RBAC) to grant the appropriate permissions for administrators and users of AI workload operators. Setting up RBAC before deploying workloads ensures that users can only access the resources they need.

== {kueue-name} RBAC

The {kueue-name} Operator deploys two default cluster roles:

kueue-batch-admin-role:: Permissions to manage cluster queues, local queues, workloads, and resource flavors. Assign this role to platform engineers and batch administrators.

kueue-batch-user-role:: Permissions to manage jobs and to view local queues and workloads. Assign this role to data scientists, ML engineers, and batch users.

For detailed procedures to bind these roles to users, see xref:../kueue/rbac-permissions.adoc#rbac-permissions[Configuring role-based permissions].
