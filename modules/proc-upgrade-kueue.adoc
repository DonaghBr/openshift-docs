= Upgrading {kueue-name}

[role="_abstract"]
Upgrade {kueue-name} to access new features and bug fixes. {kueue-name} is managed through the Operator Lifecycle Manager (OLM), which handles operator upgrades.

// TODO: Review — coordinate with Kueue engineering for version-specific upgrade notes

.Prerequisites

* You have cluster administrator privileges.
* {kueue-name} is installed on the cluster.

.Procedure

. Check the current version of the {kueue-name} Operator in the {product-title} web console or by using the CLI.

. Review the xref:../kueue/release-notes.adoc#release-notes[release notes] for the target version to identify any breaking changes or migration requirements.

. Upgrade the operator through OLM. For general OLM upgrade procedures, see xref:../../operators/admin/olm-upgrading-operators.adoc#olm-upgrading-operators[Updating installed Operators].

.Verification

* Verify that the {kueue-name} Operator pod is running with the new version.
* Verify that existing workloads and queues continue to function correctly.
