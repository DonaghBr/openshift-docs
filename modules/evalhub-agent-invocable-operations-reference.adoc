= Agent-invocable evaluation operations reference

[role="_abstract"]
{evalhub} evaluation operations are available through three interaction surfaces: the {evalhub-skills-plugin}, the {evalhub-mcp-server}, and the Python SDK or CLI.
Use this reference to look up the equivalent operation across surfaces.

== Cross-surface operations mapping

The following table maps each evaluation operation to its equivalent across the three interaction surfaces.

== Result score format

All surfaces return evaluation results in the same format:

Per-benchmark scores:: Individual scores for each benchmark in the evaluation.
Scores are typically floating point values.
The scale and interpretation depend on the benchmark.
For benchmarks with agent metadata, the `result_interpretation` and `score_ranges` fields provide context.

Weighted aggregate:: A single score computed from individual benchmark scores weighted by the collection's benchmark weights.
This provides a summary metric for the evaluation.

Pass or fail status:: Boolean pass or fail for each benchmark (compared against the benchmark's threshold) and for the collection overall (compared against the collection's aggregate threshold).
