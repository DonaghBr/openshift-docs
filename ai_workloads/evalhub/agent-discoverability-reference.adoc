= Agent discoverability API and schema reference
:context: agent-discoverability-reference

toc::[]

[role="_abstract"]
You can look up schema definitions, SDK models, Model Context Protocol (MCP) interfaces, and configuration options for agent discoverability metadata.
Agent discoverability metadata is exposed through three layers: the {evalhub} REST API with OpenAPI schemas, the Python SDK with typed model attributes, and the {evalhub-mcp-server} with tools, resources, and prompts.
Each layer surfaces the same underlying metadata with interface-appropriate access patterns.
